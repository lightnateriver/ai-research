② 数据管线深度拆解

Seedance 1.0 的数据管线是其核心竞争力之一。论文明确给出了三阶段流水线，以下是完整的 SVG 流程图和每个步骤的深度拆解。

2.1 数据预处理（5步深度拆解）

① 镜头感知时间分割

怎么做：原始长视频不直接用于训练。通过分析帧间视觉差异（inter-frame visual dissimilarities）或使用预训练的镜头边界检测器识别自然场景切换点，将长视频切分为较短片段。

关键参数：每个片段最长 12 秒，可包含一个或多个时间连贯的镜头，保留局部叙事流。

设计目的：将原始长视频切分为模型可处理的固定长度片段，同时按自然镜头边界切割而非硬切，保留镜头内的叙事连贯性，避免跨镜头语义断裂导致模型学习到混乱的时序关系。

L1

② 视觉覆盖修正

怎么做：源视频常含 logo、水印、字幕、屏幕图形等外来覆盖物。采用启发式规则系统 + 专用目标检测模型的混合方法识别这些遮挡区域，然后对帧进行自适应裁剪以最大化保留主要视觉内容。

目的：消除噪声和偏差，获得更干净、更聚焦的视频数据。

L1

③ 质量与安全过滤（双轨制）

视觉质量过滤：专用视觉质量模型系统识别并移除以下缺陷——模糊、过度抖动、低美学质量、差的电影构图、以静态内容为主的片段。

安全过滤：高级分类器检测并排除——色情、显性暴力、儿童剥削、显性裸露等有害或不当内容。

设计目的：双重保障缺一不可——质量过滤确保训练数据的视觉品质下限（模糊/抖动/低美学数据会拉低模型生成质量上限），安全过滤确保模型不学习有害内容模式，从数据源头规避安全风险。

L1

④ 语义去重

怎么做：使用内部开发的视频表征模型提取鲁棒特征 embedding，对视觉和语义相似的片段进行聚类。在每个近重复聚类中，仅保留综合质量评分最高的单个实例（质量评分来自前一步的质量过滤阶段）。

目的：促进数据集多样性，防止模型对冗余内容过拟合。

L1

⑤ 分布重平衡

怎么做：沿多个维度分析数据集分布——主体类别、场景类型、主导动作、类型（纪录片/动画等）、视觉风格、片段时长、分辨率、运动特征。

  • 头部类别（过度代表）：应用下采样（downsampling）
  • 尾部类别（代表不足）：训练时增加采样概率，同时启动定向数据采集（targeted data acquisition）扩充其存在

目标：更公平、更全面地代表视觉世界。

2.2 Video Captioning（精准视频描述系统）

密集 Caption 风格设计

Seedance 1.0 采用整合动态与静态特征的密集 caption 风格（dense caption style integrating dynamic and static features）：

动态特征（Dynamic Features）：

  • 细致描述视频片段中的动作（motions）
  • 描述相机运动（camera movements）
  • 突出变化中的元素（changing elements）
  • 主体或场景的变化

静态特征（Static Features）：

  • 详细阐述视频中核心角色或场景的特征
  • 外观（appearances）
  • 美学（aesthetics）
  • 风格（styles）

Caption 模型训练方案

  • 基座模型：Tarsier2（具有强视频理解能力的模型）
  • 训练策略：视觉编码器冻结（frozen），语言模型全量微调（fully fine-tuned）
  • 训练数据：收集上述动态/静态类别的多样化数据，进行高质量人工标注用于训练
  • 语言能力：同时在中文和英文数据上训练，获得双语能力

推理时：使用 Prompt Engineering (PE) 模型（见 D 节）将用户 prompt 重写为与训练 caption 格式对齐的详细视频描述。

③ 模型结构深度拆解

3.1 VAE：时间因果卷积变分自编码器

架构设计

遵循 MAGVIT 设计，编码器和解码器均采用时间因果卷积架构（temporally causal convolutional architecture），在 latent 空间中对图像和视频进行联合时空压缩。

压缩过程：将 RGB 像素空间输入 (T'+1, H', W', 3) 转换为连续 latent 表示 (T+1, H, W, C)。

参数取值说明
时间压缩比 r_t4时间维度下采样 4 倍
高度压缩比 r_h16空间高度下采样 16 倍
宽度压缩比 r_w16空间宽度下采样 16 倍
Latent 通道数 C48latent 表示的通道维度
总压缩比 rC/(3×r_t×r_h×r_w) = 48/(3×4×16×16) = 1/64像素到 latent 的总压缩率

关键设计：由于较高的下采样率，在 DiT 侧移除了 patchification 操作（遵循 DCAE 策略），直接使用 VAE 输出的 latent token。

因果设计优势：当 T=T'=0 时，VAE 可无缝处理图像输入输出，实现图像视频统一。

VAE 训练损失组合

四种损失联合训练：

  1. L1 重建损失：像素级绝对误差
  2. KL 散度损失：约束 latent 分布接近标准正态
  3. LPIPS 感知损失：基于深度特征的感知相似度
  4. 对抗训练损失：使用类似 PatchGAN 架构的混合判别器（hybrid discriminator），同时监督外观和运动建模，强制更精细的局部纹理和细节结构监督

3.2 Diffusion Transformer：解耦时空层 + MMDiT

解耦时空层设计（Decoupled Spatial and Temporal Layers）

核心思想：将空间注意力和时间注意力解耦为独立的层，交替堆叠：

  • 空间层（Spatial Layers）：在每一帧内部执行注意力聚合（帧内自注意力）
  • 时间层（Temporal Layers）：跨帧执行注意力计算（帧间自注意力），并在每一帧内部执行窗口划分（window partition），从而在时间维度上获得全局感受野

文本 token 参与规则：文本 token 仅在空间层参与跨模态交互，不参与时间层的注意力计算。

效率优势：解耦设计 + 窗口注意力大幅提升训练和推理效率。

L1

MMDiT 架构（多模态 Diffusion Transformer）

遵循 Stable Diffusion 3 的 MMDiT 设计：

  • 空间层：应用多模态自注意力层（multi-modality self-attention），整合视觉和文本 token
  • 时间层：仅处理视觉 token 的自注意力层
  • 双权重设计：考虑视觉和文本 token 的语义差异，在空间层中为两种模态使用两套独立权重——包括 adaptive layer norm、QKV projection、MLP
  • 训练稳定性：在注意力矩阵计算前对 Q 和 K embedding 进行归一化（QK normalization），防止训练不稳定

L1

Multishot MM-RoPE（多镜头多模态旋转位置编码）

论文原文："In addition to using 3D RoPE encoding for visual tokens, following Seaweed and LCT, we add 3D Multi-modal RoPE (MM-RoPE) in the concatenated sequences by adding extra 1D positional encoding for textual tokens. The MM-RoPE also supports interleaved sequences of visual tokens and textual tokens, and can be extended to training video with multiple shots, where shots are organized in the temporal order of actions and each shot has its own detailed caption."

① RoPE 基础原理

RoPE（Rotary Position Embedding，旋转位置编码）通过旋转矩阵将绝对位置信息注入到 query 和 key 中，使注意力分数天然包含相对位置信息：

  • 核心操作：对位置 m 的 query 施加旋转 R(mθ)，对位置 n 的 key 施加旋转 R(nθ)
  • 优势：相对位置编码、长度外推性好、与注意力机制数学上天然兼容（内积后仅依赖 m-n 的相对位置）
  • 实现方式：将 embedding 维度两两分组，每组施加不同频率 θ_i = 10000^(-2i/d) 的旋转

② 视觉 token：3D RoPE 编码

视频是三维信号（时间 t × 高度 h × 宽度 w），因此视觉 token 使用 3D RoPE：

  • 每个视觉 token 的位置由三元组 (t, h, w) 唯一确定（t=帧索引，h=空间行，w=空间列）
  • 对三个维度分别施加 RoPE 旋转：时间维度用频率 θ_t，高度维度用 θ_h，宽度维度用 θ_w
  • 3D RoPE = 三个维度旋转的组合，使注意力能同时感知"第几帧、帧内什么位置"
  • 遵循 Seaweed 和 LCT 的 3D 位置编码思路

③ 文本 token：1D RoPE 编码

文本是一维序列，没有空间维度，因此文本 token 使用标准的 1D RoPE：

  • 每个文本 token 的位置由序列中的位置 pos 确定
  • 施加标准 1D 旋转 R(pos·θ)
  • 不强行扩展为 3D——文本没有 h/w 维度，强行填充会引入无意义的位置维度，干扰注意力

④ MM-RoPE：拼接序列中的双轨位置编码

视觉 token 和文本 token 拼接成一个序列输入 DiT 空间层。MM-RoPE 的关键设计是在同一个拼接序列中，不同模态的 token 独立应用各自维度的位置编码：

  • 序列中属于视觉的位置 → 应用 3D RoPE (t, h, w)
  • 序列中属于文本的位置 → 应用 1D RoPE (pos)
  • 这就是"多模态 RoPE"（Multi-modal RoPE）的含义——不是统一用一种编码，而是按模态分别编码

⑤ 交错序列支持

MM-RoPE 不仅支持"所有文本在前、所有视觉在后"的简单拼接，还支持视觉 token 和文本 token 交错排列的序列：

  • 因为每个 token 独立应用自己模态的位置编码，不受 token 在序列中的排列方式影响
  • 视觉 token 的 3D 坐标由其在视频体素中的位置决定，而非在拼接序列中的序号
  • 文本 token 的 1D 坐标由其在 caption 中的词序决定，而非在拼接序列中的序号
  • 这为多镜头生成和复杂条件输入提供了架构灵活性

⑥ 多镜头扩展（Multishot）

MM-RoPE 可扩展到多镜头视频训练，这是 Seedance 1.0 能原生支持多镜头生成的关键：

  • 多镜头视频中，每个镜头有自己的详细 caption
  • 镜头按动作的时间顺序组织（Shot 1 → Shot 2 → ...）
  • 每个镜头的视觉 token 使用该镜头局部的 3D 坐标系（t 从 0 开始计数，而非全局帧索引）
  • 每个镜头的 caption 文本 token 使用自己的 1D 位置编码
  • 多个镜头的 (caption + visual tokens) 对按时间顺序拼接，形成交错序列
  • MM-RoPE 天然支持这种结构——因为每个 token 独立编码，镜头边界不需要特殊处理
交错序列（interleaved sequences）：文本 token 和视觉 token 按 [Shot1文本 | Shot1视觉 | Shot2文本 | Shot2视觉] 的顺序拼接，每个 token 独立应用自己模态的位置编码 MM-RoPE 如何应用到这个序列： ① 蓝色/红色文本 token → 应用 1D RoPE（pos=0,1,2，每个镜头的 caption 独立计数）；② 绿色/黄色视觉 token → 应用 3D RoPE（t,h,w，每个镜头局部坐标系，t 从 0 开始）；③ 镜头边界不需要特殊处理，因为每个 token 独立编码 图例： Shot1 文本 Token（1D RoPE） Shot1 视觉 Token（3D RoPE） Shot2 文本 Token（1D RoPE） Shot2 视觉 Token（局部 3D 坐标） 注：RoPE 旋转频率 θ_i = 10000^(-2i/d)；3D RoPE 对 t/h/w 三维度分别施加旋转后组合；实际训练中视觉 token 数量远大于此示例（数百至数千个），此处仅展示结构原理；论文未披露具体频率分配和维度划分细节。 示例中视觉 token 简化为 2帧×1行×2列=4个/镜头，实际为 T帧×H行×W列的完整体素网格。
设计目的：
  • 为什么视觉用 3D 而文本用 1D？视频的时空结构需要 3D 编码才能同时表达帧内空间关系（h,w）和帧间时间关系（t）；文本没有空间维度，强行用 3D 会引入无意义的 h/w 位置，干扰注意力学习。
  • 为什么在拼接序列中分别编码而非统一编码？统一编码会迫使文本 token 学习不存在的空间维度，或迫使视觉 token 丢失时空结构信息。按模态分别编码（MM-RoPE）让每种模态使用最适合自身的位置表示。
  • 为什么支持交错序列？多镜头生成中每个镜头有自己的 caption，天然形成"文本-视觉-文本-视觉"的交错排列。如果位置编码不支持交错，就无法在单个模型中统一处理多镜头输入。
  • 为什么多镜头用局部 3D 坐标系而非全局？每个镜头是独立的叙事单元，镜头间的时间间隔不固定（可能是切、叠化、跳切），用全局帧索引会导致位置编码分布不均且语义混乱。局部坐标系让每个镜头的 t=0 都代表"镜头开始"，语义更清晰。

论文未披露：3D RoPE 三个维度（t/h/w）的具体频率分配方案、旋转维度如何在 embedding 维度间划分、多镜头训练时 caption 与 visual 的具体拼接比例和排列方式。

统一任务公式（Unified Task Formulation）

怎么做：为实现条件视频生成，将带噪输入（noisy inputs）与干净帧或零填充帧（cleaned or zero-padded frames）沿通道维度拼接，并使用二进制掩码（binary masks）指示哪些帧是需要遵循的指令帧。

统一效果：通过此公式，可以统一不同生成任务——文生图（T2I）、文生视频（T2V）、图生视频（I2V）。训练时混合这些任务，通过控制条件输入来调整比例。

L1

3.3 Diffusion Refiner：级联超分扩散模型

怎么做：采用级联扩散框架（cascaded diffusion framework）生成高分辨率视频：

  1. Base 模型先生成 480p 视频
  2. Diffusion Refiner 模型将 480p 视频上采样到 720p 或 1080p 高分辨率视频，增强视觉细节和纹理

Refiner 训练：

  • 从预训练 Base 模型初始化（非从零训练）
  • 与 Base 不同，Refiner 以低分辨率（LR）视频为条件进行训练
  • 具体做法：LR 视频先上采样到高分辨率，然后与扩散噪声沿通道维度拼接，形成 DiT 的输入

L1

3.4 Prompt Engineering (PE)：用户 prompt 重写系统

由于 DiT 训练使用的是密集视频 caption 格式，而用户输入的是自然语言 prompt，需要一个 PE 模型将用户 prompt 转换为对应的 caption 格式。

基座：Qwen2.5-14B

两阶段训练：

  1. SFT 阶段：人工标注大量用户 prompt 及其密集 caption 表达。特别区分 I2V 和 T2V 任务（因为用户 prompt 风格不同），采用全量微调策略获得基础改写能力
  2. RL 阶段：由于模型幻觉的存在，SFT 结果不能保证改写语义完全符合用户 prompt。收集正确和错误改写结果的配对数据，执行 DPO（Direct Preference Optimization）训练。此阶段在 SFT 模型上使用 LoRA（Low-Rank Adaptation）微调策略

L1 PE 模型设计完整披露

设计目的：用户输入的自然语言 prompt 与训练用的密集 caption 格式存在分布差异，PE 模型作为"翻译层"将用户意图转换为模型熟悉的描述格式，SFT 学基础改写能力，DPO 纠正幻觉导致的语义偏移，二者配合确保用户意图被准确传达。

④ 训练整体情况深度拆解

4.1 Pre-Training 预训练

扩散调度（Diffusion Scheduling）

论文原文："During training, we employ the flow matching framework with velocity prediction, and a training timestep is sampled from a logit-normal distribution. Considering that videos with higher resolution and longer duration require more noise to disrupt their signal, we then transform the training timestep with a resolution-aware shift, which increases the noise perturbation for videos with higher resolution and longer duration."

① Flow Matching + Velocity Prediction（简要）

  • Flow Matching：学习从噪声分布到数据分布的确定性传输轨迹（ODE），相比 DDPM 的随机过程有更直的生成轨迹，推理步数更少
  • Velocity Prediction：模型预测的是速度场 v_t(x) = dx/dt（数据与噪声的线性插值方向），而非 DDPM 中的噪声 ε 或 x_0。velocity prediction 对不同噪声水平的预测更稳定，训练收敛更快
  • 带噪样本构造：x_t = (1-t)·x_0 + t·x_1，其中 x_0 是干净数据，x_1 ~ N(0,I) 是纯噪声，t ∈ [0,1]

② Logit-Normal Timestep 采样（详细展开）

什么是 logit-normal 分布？

  • 先从正态分布采样：z ~ N(μ, σ²)
  • 再通过 sigmoid 变换得到 timestep：t = sigmoid(z) = 1 / (1 + e^(-z))
  • 由于 sigmoid 在 z=0（对应 t=0.5）附近斜率最大，相同 dz 对应更大的 dt，导致 t 的概率密度在 t≈0.5 附近最高，呈现"中间高、两端低"的钟型/倒 U 型分布（标准参数 μ=0 时）
  • 概率密度函数：f(t) = [1/(σ√(2π))] · [1/(t(1-t))] · exp(-(logit(t)-μ)²/(2σ²))，其中 logit(t) = ln(t/(1-t))
  • 等价理解：log-SNR λ = 2·logit(t) 均匀分布，即每个 SNR 数量级（octave）获得相同训练权重，比 t 均匀更符合感知对数特性（SD3 论文的设计动机）

均匀采样的问题：

  • 如果 t ~ Uniform(0,1)，每个噪声水平被采样的概率相同
  • 但在实际训练中，中间区域 t≈0.5 的噪声/信号比最复杂、最难预测——信号和噪声各半，模型既要推断全局结构又要恢复局部细节，梯度信息最复杂、学习难度最高
  • 两端（t→0 和 t→1）反而相对简单：t→0 时信号几乎完整，模型只需微调；t→1 时几乎全是噪声，模型只需"猜噪声"
  • 结果：均匀采样给每个区域相同权重，导致最难的中间区域训练不足，而简单的两端被过度训练

Logit-normal 如何解决：

  • 钟型分布主动提升中间区域（t≈0.5）的采样概率，降低两端（t→0 和 t→1）的采样概率
  • 这让最难的中间区域获得更多训练样本，确保模型在信号/噪声最复杂的阶段得到充分学习
  • SD3 论文在 61 种配方（epsilon/v-prediction、EDM、rectified flow、linear/cosine schedule 等）的大规模对比中，logit-normal + rectified flow 表现最优

不同噪声水平的学习难度：

  • 高噪声区域（t → 1，噪声占主导）：x_t 几乎是纯噪声，模型预测目标接近纯噪声，任务相对简单——"猜噪声"不需要理解语义结构
  • ★ 中等噪声区域（t ≈ 0.5）：信号和噪声各占一半，模型既要从噪声中推断全局结构，又要恢复局部细节，梯度最复杂、学习难度最高——这是 logit-normal 重点采样的区域
  • 低噪声区域（t → 0，信号占主导）：x_t 已经很接近干净数据，模型只需做局部微调，任务相对简单——"精修"不需要大幅改变结构
  • 注意：高噪声学全局结构、低噪声学细节纹理的说法在定性上成立，但从学习难度角度看，两端都比中间简单，这正是 logit-normal 集中在中间的原因

②.5 消融对比：Logit-Normal vs Uniform vs Timestep Shifting vs Curriculum Sampling

核心结论（修正）：Logit-Normal 和 Uniform 之间不是简单的"谁更好"，而是存在速度-质量权衡：

  • Logit-Normal：早期收敛快（40k-90k steps FID 更低），但欠采样边界区域导致最终质量更差（性能天花板）
  • Uniform：早期收敛慢，但持续稳定提升，最终 FID 优于所有纯 Logit-Normal
  • Curriculum Sampling（LN → Uniform）：兼具两者优势，最终质量和收敛速度都最优

★ Curriculum Sampling 详细做法（Stanford, arXiv:2603.12517, 2026）

核心动机——U 型损失曲线发现：

  • 论文实际测量了 per-timestep 训练损失 L(t) = E[‖v_θ(z_t,t) - v_t(z_t|x)‖²]
  • 发现损失呈现U 型：t→0（数据端）损失最大，t→1（噪声端）也较高，中间 t≈0.5 损失最低
  • 这意味着边界区域才是最难收敛的：
    • t→0：信号几乎完整，模型需要学习精确的精细细节（纹理、边缘、色彩），差一点就明显
    • t→1：几乎全噪声，模型需要学习精确的噪声分布和初始结构，起点错了后面全错
    • t≈0.5：信噪比最复杂，但模型在中间区域学得快（损失低），因为结构和细节都不需要特别精确
  • 这与 SD3"中间最难"的说法形成 nuance：中间信噪比最复杂（信息论角度），但实际训练损失最低（收敛角度）；边界信噪比简单，但收敛最难

速度-质量权衡的发现：

  • Logit-Normal（中间侧重）：把计算资源集中在 t≈0.5，快速学全局结构 → 早期 FID 下降快（40k-90k steps 优于 Uniform），但欠采样边界 t→0,1 → 精细细节学不到 → 90k 后饱和，最终 FID 更差
  • Uniform：均匀覆盖所有 t → 早期结构学习慢 → 早期 FID 高，但边界区域得到充分训练 → 持续提升，150k 反超所有 LN
  • 这是一个交叉现象（crossover）：LN 早期领先，Uniform 后期反超

两阶段课程做法：

快速学全局结构（主体、构图、动作） 特点：FID 下降快，但边界细节欠训练 → Ts 切换 （超参数，如80k） Phase 2: Refinement Phase（精修阶段） Ts ~ 结束 steps（如 80k~150k） 采样分布：Uniform（均匀覆盖全区间） t=0 ─────────── t≈0.5 ─────────── t=1 目标：补充边界训练，学精细细节 特点：t→0 学纹理细节，t→1 学噪声起点 结果：FID 3.22（优于 Uniform 3.85 和纯 LN 4.03），100k steps 达峰值（vs Uniform 150k），质量+速度双优

具体步骤：

  1. Phase 1（0 ~ Ts steps）：使用 Logit-Normal 采样（钟型分布，集中 t≈0.5），让模型快速学习全局结构和语义布局。此阶段 FID 下降最快。
  2. 切换点 Ts：当模型全局结构基本学完（FID 下降开始放缓），在 Ts steps 处切换采样分布。Ts 是超参数，论文实验中约为总训练步数的 50-60%。
  3. Phase 2（Ts ~ 结束）：切换为 Uniform 采样，均匀覆盖 t∈[0,1] 全区间，重点补充之前欠采样的边界区域 t→0（学精细细节）和 t→1（学精确噪声起点）。
  4. 注意：切换的是训练时的 timestep 采样分布 p(t)，不是模型架构、损失函数或推理调度。模型权重连续训练，不重置。

Timestep Shifting（HunyuanVideo 风格）与上述策略的关系：

  • 二者不是互斥的替代关系，作用阶段不同：
    • Logit-normal / Uniform / Curriculum：训练时的 timestep 采样分布 p(t)，决定训练计算资源分配
    • Timestep shifting：推理时的调度调整，通过偏移因子 s 改变推理时 t 的分布（偏向高噪声端），用于补偿低步数推理（HunyuanVideo：50步用 s=7，<20步用 s=17）
  • 有些工作（LoomVideo 2026）同时使用两者：训练用 curriculum/logit-normal，推理用 dynamic timestep shift
  • Timestep shifting 消融（End-to-End AR Video Diffusion 2025）：s 太小→误差累积质量下降；s 太大→语义一致性下降内容漂移；需要适中值

其他新兴采样策略（详细展开）：

(1) TQD — Timestep-aware Quality Decoupling（CVPR 2026, Wan/CogVideoX）

核心动机——Motion-Vision Quality Dilemma：

  • 视频数据中视觉质量(VQ)和运动质量(MQ)呈负相关（Pearson r=-0.2187, p<0.001）——运动越激烈的视频往往画面越容易模糊/压缩，画面越精美的视频往往运动越平淡
  • 同时高VQ和高MQ的"黄金数据"仅占 21.9%；高MQ/低VQ和高VQ/低MQ各占约 28%
  • 传统数据过滤为什么丢弃它们？传统管道用多维度联合阈值过滤——要求视频同时满足"VQ≥阈值"且"MQ≥阈值"才保留。由于VQ和MQ负相关，大量单维度突出的数据因"另一项不达标"被直接扔掉。TQD的核心思路就是：不扔，而是把每个数据放到它最擅长的timestep去学
  • 关键发现：视频扩散模型去噪是分层的——高噪声阶段(t大)建立运动和构图，低噪声阶段(t小)细化细节和纹理
  • 梯度分析（120样本，3种VQ退化+1种MQ退化）证实：高MQ/低VQ数据在高timestep与黄金数据梯度相似（适合学运动）；高VQ/低MQ数据在低timestep与黄金数据梯度相似（适合学细节）

具体做法——两级自适应机制：

  1. Sample-Level Weighting（样本级加权/质量dropout）：
    • VQ/MQ分数怎么来的？用 VideoAlign 框架预计算——这是一个视频质量评估模型，分别输出视觉质量(VQ)和运动质量(MQ)分数。论文特别说明：原始VideoAlign在生成视频上训练，他们在真实视频上重新训练了该模型，以更适合评估自然视频分布
    • 所有样本的VQ和MQ分数通过 min-max 归一化到 [0,1]
    • 每个样本以概率 p_sample = max(vq_norm, mq_norm) 被采样进batch（注意：是在PrepareBatch阶段按此概率抽样，不是训练时随机mask）
    • 双低样本怎么处理？不是硬丢弃，是软降权（概率加权采样）。例如 vq=0.2, mq=0.1 的双低样本，p=0.2，意味着训练中被抽到的概率是20%，出现频率低但不是完全排除。而 vq=0.9, mq=0.8 的黄金数据 p=0.9，几乎每次都被保留
    • 效果：至少有一个维度强的样本获得足够训练，双低样本因采样概率低而自然减少训练占比
  2. Timestep-Level Distribution Adjustment（时间步级分布调整）：
    • 对保留样本，用质量相关的 Beta 分布参数化 timestep 分布：p(t|x₀) ∝ Beta(t; μκ, (1-μ)κ)
    • 中心参数 μ（相对质量差异）：μ = 0.5 + 0.5×(mq_norm - vq_norm)
      • 高MQ/低VQ（μ>0.5）→ 分布偏向高timestep → 学运动
      • 高VQ/低MQ（μ<0.5）→ 分布偏向低timestep → 学细节
    • 集中度参数 κ（质量差异程度）：κ = κ_base + (κ_max-κ_base)×|mq_norm-vq_norm|
      • 差异越大 → κ越高 → 分布越尖锐 → 更强的timestep专业化
      • 平衡样本（黄金数据）→ 分布平坦 → 接近基线采样
      • κ_base 设置：CogVideoX=2（匹配uniform Beta(1,1)），Wan=4（近似logit-normal）
  3. 组合分布：p(t) ∝ max(vq_norm, mq_norm) × Beta(t; μκ, (1-μ)κ)

(2) CACFM / Loss-Aware Sampling（arXiv 2026, FLUX/SDXL）

核心发现——Consistency Distillation 的 U 型难度曲线：

  • 标准迭代生成训练中，中间步骤最难（Logit-Normal 的假设基础）
  • 但 Consistency Distillation 中，Oracle Consistency Error 呈 U 型分布——边界阶段（t→0 初始化和 t→1 最终细化）才是真正的几何瓶颈
  • Logit-Normal 先验对 consistency distillation 是几何错位的（集中在中间，但中间反而是最简单的）

Loss-Aware Sampling（简单动态版）：

  • 用 per-stage consistency loss 的 EMA（指数移动平均）动态更新阶段采样概率：p(stage) ∝ EMA[loss(stage)]
  • 损失高的阶段多采样，损失低的阶段少采样
  • 缺点：myopic（短视）——只看当前损失，没有状态转移建模和时间信用分配

CACFM（完整版，RL 驱动的曲率自适应）：

  1. 将子轨迹选择建模为 MDP（马尔可夫决策过程）
  2. 语义阶段抽象：将连续轨迹 t∈[0,1] 划分为 M=4 个粗几何阶段：Initialization → Structural Formation → Texture Filling → Final Refinement
  3. 状态空间：各阶段当前损失的相对排名（低维离散空间）
  4. 动作空间：选择哪个阶段进行采样
  5. 奖励：该阶段一致性损失的减少量（优化收益）

③ 分辨率感知 Shift（详细展开）

为什么高分辨率/长时长视频需要更多噪声？

  • 在 flow matching 中，带噪样本 x_t = (1-t)·x_0 + t·x_1，信噪比 SNR ∝ (1-t)²·||x_0||² / (t²·||x_1||²)
  • 高分辨率视频：x_0 的维度更高（更多像素），信号总能量 ||x_0||² 更大。在相同 t 下，SNR 更高——意味着信号没有被噪声充分破坏，模型"看到了太多答案"，学习任务变简单，梯度信息不足
  • 长时长视频：更多帧意味着更高的信号维度，且帧间的时间相关性提供了额外的统计信号（相邻帧相似，可以互相"猜"出被噪声掩盖的部分），进一步提高了有效 SNR
  • 结果：如果对所有规格视频用相同的 t 分布，高分辨率/长时长视频的实际训练难度低于低分辨率/短视频，导致模型在高规格数据上学不充分

Shift 如何工作：

  • 对采样得到的 timestep t 施加一个与分辨率和时长相关的偏移变换：t' = shift(t, resolution, duration)
  • 分辨率越高、时长越长 → shift 越大 → t' 越偏向高噪声端（t→1）
  • 通过增大 t'，增加噪声比例 (t')²，降低 SNR，让高规格视频的信号被充分破坏
  • 最终效果：不同规格视频在训练时获得相似的有效信噪比和学习难度，避免高规格数据"太简单"而学不充分

直观理解：

  • 低分辨率短视频（256px, 3s）：信号弱，少量噪声就能"遮住"，不需要 shift 或 shift 很小
  • 高分辨率长视频（640px, 12s）：信号强（像素多+帧多+时间相关性），需要"更大声的噪声"才能遮住，shift 将 t 向高噪声端推
  • 类比：给小学生和大学生出同一张试卷，大学生觉得太简单学不到东西；需要给大学生出更难的题（更大的 shift = 更多噪声 = 更难的任务）
设计目的（展开版）：
  • Flow Matching + Velocity Prediction：Flow Matching 学习确定性 ODE 轨迹，比 DDPM 的随机过程轨迹更直、推理步数更少；velocity prediction 预测速度场 v=dx/dt，对不同噪声水平的预测比 ε-prediction 更稳定，二者结合提升收敛速度和生成质量。
  • Logit-Normal 采样：均匀采样下中间区域 t≈0.5 的噪声/信号比最复杂、最难预测，但均匀采样给每个区域相同权重，导致最难的中间区域训练不足。logit-normal 的钟型分布（SD3 首创）集中在 t≈0.5，给最难区域更多训练样本；等价于让 log-SNR 均匀分布，每个 SNR 数量级获得相同权重。多项独立消融证实 logit-normal 显著优于均匀采样（见下方消融对比）。
  • 分辨率感知 Shift：高分辨率/长时长视频的信号维度更高（像素多+帧多+时间相关性强），在相同 t 下 SNR 更高、信号未被充分破坏，学习任务"太简单"导致梯度信息不足。shift 将高规格视频的 t 向高噪声端偏移，增加噪声比例，让不同规格视频获得相似的有效 SNR 和学习难度，避免高规格数据学不充分。

论文未披露：① logit-normal 分布的具体参数 μ 和 σ；② 分辨率感知 shift 的具体公式（线性/非线性、基于分辨率和时长的什么函数）；③ shift 在训练不同阶段是否有不同参数。

4.2 Continue Training (CT) 继续训练

为什么需要 CT：预训练中 I2V 任务仅占 20%，模型在该领域的潜力未充分挖掘。CT 阶段专门强化 I2V 生成能力。

具体做法：

  1. I2V 比例提升：从 20% 提升到 40% —— 目的：预训练阶段 I2V 占比低导致能力不足，CT 专门强化图像条件生成，提升 I2V 的质量和可控性
  2. 高质量数据选择：使用一系列专用评估模型从预训练数据中选择子集——美学评分器（aesthetic scorer）+ 基于光流的运动评估器（motion evaluators based on optical flow），筛选出更高美学质量和更丰富运动动态的数据 —— 目的：CT 阶段用更高质量数据精调，美学评分器筛选视觉品质，光流评估器筛选运动丰富性，避免低质量数据拉低模型上限
  3. 双 Caption 设计（长短 Caption 混合训练）：由于 I2V 任务中第一帧总是给定的，设计两种 caption 版本在 CT 阶段混合训练：
    • 长 Caption：完整描述 = 动态特征（动作+相机运动）+ 静态特征（外观+美学+风格）
    • 短 Caption：仅保留运动动态描述，移除与第一帧对应的静态描述（因为静态信息已由第一帧图像提供）
    • 怎么一起训：训练数据中同时包含两种 caption 的样本，按一定比例混合喂给模型（数据集层面按比例采样，不是每个样本同时跑两次 forward）。论文未披露具体混合比例
    • 使用范围：仅在 CT 阶段使用，预训练阶段用统一的 dense caption（含动态+静态）
    设计目的（直觉解释）：I2V 任务中第一帧图像已经告诉模型"这个人长什么样、穿什么衣服、在什么场景"，如果 caption 里再重复一遍静态描述，模型可能过度依赖文本而忽略图像输入。短 Caption 强制模型形成"从图像看静态，从文本看运动"的分工，避免冗余监督，增强运动生成质量和文本-运动语义对齐。
  4. 训练策略——退火学习率调度（annealed learning rate schedule）：
    • 什么是退火学习率：学习率随训练步数逐渐衰减（退火）的调度策略。训练初期用较大学习率快速适应新数据分布，后期逐步减小学习率精细调整参数，缓慢收敛到最优解
    • 常见退火方式：cosine annealing（余弦退火）、linear decay（线性衰减）、step decay（阶梯衰减）等。论文未披露具体使用哪种退火方式
    • CT 阶段为什么用退火：CT 在预训练基础上精调，模型已经有较好的通用能力。退火学习率让模型先快速适应 CT 的高质量数据和 I2V 强化目标，再缓慢收敛，避免大学习率破坏预训练学到的通用能力（灾难性遗忘）
    • 其他训练配置：使用比预训练稍少的 GPU（CT 数据量小于预训练，不需要大规模分布式）
    设计目的：退火学习率是精调阶段的标准技巧——初期大学习率快速跨越损失地形的初始平坦区域，后期小学习率在最优点附近精细搜索，既保证收敛速度又避免震荡。配合 CT 阶段的高质量数据，能在不破坏通用能力的前提下显著提升 I2V 和 T2V 的视觉保真度。

工作负载均衡（Runtime-aware Workload Balancing）详细展开

问题根源：大规模视频预训练中，一个 batch 内可能同时包含 5 秒 1080p 长视频和 2 秒 480p 短视频，token 数和 FLOPs 差异可达 5-10 倍。如果按顺序静态分配 GPU，拿到长视频的 GPU 计算量远大于短视频的 GPU，快的 GPU 等慢的 GPU（木桶效应），产生大量空闲时间。

论文具体做法：

  1. 额外 all-to-all 通信步骤：在每个 batch 内，通过 all-to-all 集体通信将各 GPU 上的样本/token 重新分配，使每个 GPU 的总计算量趋于均匀
  2. Batch 内执行：均衡操作在每个 batch 内执行（不是全局静态分配），以保持数据一致性——每个 batch 的数据分布不同，需要动态调整
  3. 异步预计算：均衡方案在后台异步预计算，不阻塞主训练循环，避免增加 critical path 延迟

4.4.2 后训练优化（Post-Training Optimization）

后训练主要包括 SFT、RL、蒸馏三个阶段，核心挑战是优化训练效率的同时最小化 GPU 内存消耗。

三大内存挑战来源：

  1. Memory Contention（内存争用）：多阶段训练中不同模块竞争有限 GPU 内存
  2. Complex Training Modes（复杂训练模式）：SFT/RL/蒸馏各有不同的计算图和内存需求
  3. Diverse Workloads（多样化工作负载）：不同任务和数据类型导致内存使用波动

解决方案——动态内存管理框架 + 并行策略：

① 动态内存管理框架（核心创新）：

  • CPU Offloading：使用 PyTorch hooks 实现 CPU offloading，最小化对用户代码的侵入——通过前向/反向 hook 在需要时把张量从 CPU 搬回 GPU，用完立即卸载回 CPU
  • Recomputation：对激活值不存储而是反向时重新计算，通过详细 profiling 和建模确定最优的 offloading 和 recomputation 策略（哪些张量 offload、哪些重计算、哪些保留在 GPU）
  • 局部静态内存规划：针对频繁分配/释放不同大小张量导致的内存碎片，应用局部静态内存规划减少碎片

② 并行策略（复用+定制）：

  • FSDP + 序列并行：复用预训练的并行方案，利用 FSDP + 序列并行实现多节点扩展
  • 差异化并行度配置：不同模型（Text Encoder / DiT / VAE / Reward Model）按计算特征配置不同的序列并行度

  • FSDP 冻结参数管理：手动管理 free_event_queue 解决 FSDP 在参数冻结时的延迟释放问题；使用 register_post_backward_reshard_only_hook 调整冻结模式下反向计算的内存分配和释放顺序
设计目的：后训练阶段（尤其 RLHF/蒸馏）需要同时加载生成模型、Reward Model、VAE、Text Encoder 及各自优化器状态和激活张量，内存压力远大于预训练。动态内存管理框架通过 PyTorch hooks 非侵入式 CPU 卸载 + 选择性重计算 + 防碎片，在有限 GPU 内存下完成多模型共存的复杂训练流程；FSDP+序列并行复用预训练成熟方案，但针对后训练多模型特点做了差异化并行度和冻结参数内存管理的定制。

Loss 构成——复合奖励的线性组合

Base Model RLHF（4.4.3）：

  • 训练时模拟视频推理流水线，直接预测 x0（干净视频）
  • 用三个 RM 分别评估生成的视频，得到三个奖励分数
  • 直接最大化多个 RM 的复合奖励（composite rewards）

Super-Resolution RLHF（4.4.4）：

  • 论文明确说"直接最大化这些奖励信号的线性组合（linear combination）"
  • 低分辨率 VAE latent 作为条件输入，生成的高分辨率视频由多个 RM 评估

Loss 形式（推断）：

Loss = - ( w₁ · Rfoundational + w₂ · Rmotion + w₃ · Raesthetic )

即最小化负的加权奖励和。训练目标是让生成视频在三个维度上同时获得高奖励。

论文未披露：① 具体权重 w₁/w₂/w₃ 的数值；② 三个 RM 的分数是否归一化到同一量纲后再加权；③ Base Model RLHF 和 Super-Resolution RLHF 是否使用相同的权重配置。论文只说"线性组合"和"复合奖励"，未给出具体权重。

多轮迭代学习：在扩散模型和 RM 之间做多轮迭代——模型生成新视频 → RM 评估 → 模型更新 → 再生成，逐步提升性能上限。比动态更新 RM 更稳定可控，避免 RM 和生成模型"共同漂移"导致训练崩溃。

对比实验结论：论文对比了 DPO / PPO / GRPO 三种算法，证明直接奖励最大化在扩散模型上最高效有效——DPO 受限于偏好对质量且无法利用连续 reward，PPO/GRPO 训练不稳定且需要 Critic/组内采样，直接最大化可充分利用三维度连续 reward 信号。

核心原因：三个维度评估空间不同，需要不同的模型架构和输入形式。

四种 RLHF 优化算法详细拆解

① DPO（Direct Preference Optimization，直接偏好优化）

提出：Rafailov et al., 2023

核心思想：将 RLHF 转化为分类问题，直接用偏好对（chosen/rejected）训练策略模型，不需要显式 reward model，不需要在线采样。

流程：

  1. 收集偏好对数据：同一个 prompt 下，人类偏好的视频 y_w（chosen）和不偏好的视频 y_l（rejected）
  2. 用偏好对直接训练策略模型 π，最大化 chosen 的对数概率，最小化 rejected 的对数概率
  3. 引入参考模型 π_ref（通常是 SFT 模型）作为正则，防止策略漂移过大

损失函数：

L_DPO = -log σ( β · [log π(y_w|x)/π_ref(y_w|x) - log π(y_l|x)/π_ref(y_l|x)] )

优点：① 简单稳定，训练流程最简洁；② 不需要 reward model，省去 RM 训练成本；③ 不需要在线采样，计算成本最低；④ 不需要 Critic 网络

缺点：① 受限于偏好对质量——偏好对数量和质量直接决定上限；② 无法利用连续 reward 信号——只能二分类偏好（好/坏），无法利用"好多少"的连续信息；③ 扩散模型上效果非最优（论文对比实验证明）

偏好对详细举例

标注过程：

Prompt："一只金毛犬在阳光下的草地上奔跑，慢动作，电影质感"

SFT 模型用此 prompt 生成 4 个视频：

  • 视频A：金毛犬四肢协调奔跑，阳光透过毛发，背景清晰，电影质感强
  • 视频B：金毛犬在跑，但后腿偶尔畸形（5条腿），画面有闪烁
  • 视频C：金毛犬在走（不是跑），动作缓慢，但画面质量很好
  • 视频D：金毛犬在跑，动作自然，但背景模糊，色彩偏灰

标注者在"运动质量"维度下判断：

  • ✅ 最好（chosen）= 视频A（奔跑自然、协调、无伪影）
  • ❌ 最差（rejected）= 视频B（畸形问题最严重，运动伪影明显）

偏好对 = (prompt, 视频A, 视频B)

偏好对数据结构：

preference_pair = {
  "prompt": "一只金毛犬在阳光下的草地上奔跑...",
  "chosen": 视频A的latent,   # 标注者认为最好的
  "rejected": 视频B的latent,  # 标注者认为最差的
  "dimension": "运动质量",     # 在哪个维度下选的最好/最差
}

为什么只选最好和最差（中间的视频C、D不用）？

  • 偏好信号最强：最好 vs 最差差异最大，loss 梯度更明显，训练更高效
  • 标注简单：标注者只需判断"哪个最好、哪个最差"，不需要给所有视频排序
  • 避免模糊偏好：中间视频之间差异小，标注者难以判断，容易引入标注噪声
  • DPO 只需要一对：DPO loss 只需要一个 chosen 和一个 rejected，不需要全排序

中间视频（C、D）怎么处理？

  • 不直接参与这个偏好对的训练（被丢弃）
  • 但可能被用于其他维度的偏好对：比如在"美学质量"维度下，最好可能是视频C（画面质量好），最差可能是视频D（背景模糊）
  • 同一个 prompt 可以在不同维度下生成多个偏好对，提高数据利用率
关键约束：最好在其他维度不劣于最差。Seedance 论文明确要求"ensuring that the best videos are not inferior to the worst ones in other dimensions"。例如在"运动质量"维度下选 chosen=A、rejected=B，但要确保 A 在美学、图文对齐等其他维度上不比 B 差。否则模型可能学到"运动好=美学差"的错误关联。这个约束确保模型学到的是"在其他条件相同的情况下，运动好的更受偏好"，而不是被其他维度的差异干扰。

② PPO（Proximal Policy Optimization，近端策略优化）——详细展开

提出：Schulman et al., 2017（OpenAI）

核心思想：Actor-Critic 框架——Actor（策略模型）负责生成动作，Critic（价值网络）负责评估动作好坏。通过裁剪的目标函数限制策略更新幅度，保证训练稳定。

PPO 的三个核心组件

组件作用输入输出
Actor（策略模型 π） 根据状态生成动作（在扩散模型中，动作 = 去噪步骤的预测） 状态 s（带噪 latent + prompt） 动作 a（去噪方向）的概率分布
Critic（价值网络 V） 评估状态的好坏，即从当前状态开始的期望累计奖励 状态 s 状态价值 V(s)（标量）
Reward Model（RM） 评估生成视频的质量，给出连续奖励分数 生成的视频 + prompt 奖励 r（标量，连续分数）

关键概念详解

① 状态价值 V(s)：从状态 s 开始，按照当前策略执行，能获得的期望累计奖励。

V(s) = E[ r₁ + γr₂ + γ²r₃ + ... | s ] （γ 是折扣因子，通常 0.99）
V(s) 高 = 从这个状态开始，未来能获得高奖励；V(s) 低 = 这个状态不好，未来奖励低。

② 优势函数 A(s,a)：在状态 s 下执行动作 a，比"平均水平"好多少。

A(s,a) = r + γ·V(s') - V(s)
- A > 0：这个动作比平均好，应该增加其概率 - A < 0：这个动作比平均差，应该降低其概率 - A = 0：这个动作和平均一样，不需要调整

③ GAE（Generalized Advantage Estimation，广义优势估计）：实际 PPO 中用 GAE 计算优势，平衡偏差和方差。

A_GAE = Σₖ (γλ)ᵏ · δₜ₊ₖ ，其中 δₜ = rₜ + γV(sₜ₊₁) - V(sₜ)
λ 是 GAE 参数（通常 0.95），λ=1 是 Monte Carlo（无偏差但高方差），λ=0 是单步 TD（有偏差但低方差）。

④ 新旧策略概率比 ratio：当前策略 π_θ 生成动作 a 的概率，相对于旧策略 π_θ_old 的比值。

ratio = π_θ(a|s) / π_θ_old(a|s)
- ratio = 1：当前策略和旧策略一样 - ratio > 1：当前策略比旧策略更可能生成这个动作 - ratio < 1：当前策略比旧策略更不可能生成这个动作

PPO 裁剪目标——核心创新

PPO 的损失函数：

L_PPO = E[ min( ratio·A, clip(ratio, 1-ε, 1+ε)·A ) ] - β·KL(π_θ || π_ref)

裁剪的直觉（为什么需要 clip）：

  • 如果 A > 0（动作好），我们想增加这个动作的概率（ratio 增大）。但如果 ratio 超过 1+ε，就裁剪到 1+ε——防止策略更新过大，避免"一步迈太大"导致训练崩溃
  • 如果 A < 0（动作差），我们想降低这个动作的概率（ratio 减小）。但如果 ratio 低于 1-ε，就裁剪到 1-ε——同样防止更新过大
  • min 的作用：取 ratio·A 和 clip(ratio)·A 中较小的那个。当 ratio 在 [1-ε, 1+ε] 范围内时，两者相等，正常更新；当 ratio 超出范围时，clip 后的值更小，限制更新幅度

ε 的含义：裁剪范围，通常 0.1 或 0.2。ε=0.2 表示 ratio 允许在 [0.8, 1.2] 范围内自由变化，超出就被裁剪。

KL 正则项：-β·KL(π_θ || π_ref)，防止当前策略偏离参考模型（通常是 SFT 模型）太远，保持训练稳定。β 是 KL 惩罚系数。

PPO 完整训练循环

  1. 在线采样：用当前策略 π_θ 对一批 prompt 生成视频，记录每个状态 s、动作 a、奖励 r（由 RM 评估）
  2. 计算状态价值：用 Critic V 评估每个状态的 V(s)
  3. 计算优势函数：用 GAE 计算每个 (s,a) 的优势 A(s,a)
  4. 计算 ratio：用当前策略 π_θ 和旧策略 π_θ_old 计算每个动作的 ratio
  5. 计算 PPO 损失：L = E[min(ratio·A, clip(ratio,1-ε,1+ε)·A)] - β·KL
  6. 更新 Actor：梯度下降更新策略模型 π_θ
  7. 更新 Critic：用 MSE 损失更新价值网络 V（让 V(s) 更接近实际累计奖励）
  8. 重复：回到步骤 1，用更新后的策略继续采样

数值例子

假设：ε=0.2（裁剪范围 [0.8, 1.2]），A=2.0（这个动作比平均好很多）

情况1：ratio=1.1（在范围内）

  • ratio·A = 1.1 × 2.0 = 2.2
  • clip(ratio)·A = 1.1 × 2.0 = 2.2（未被裁剪）
  • min = 2.2 → 正常更新，增加这个动作的概率

情况2：ratio=1.5（超出范围）

  • ratio·A = 1.5 × 2.0 = 3.0
  • clip(ratio)·A = 1.2 × 2.0 = 2.4（被裁剪到 1.2）
  • min = 2.4 → 限制更新幅度，防止策略一步迈太大

情况3：A=-1.5（动作差），ratio=0.7（超出下限）

  • ratio·A = 0.7 × (-1.5) = -1.05
  • clip(ratio)·A = 0.8 × (-1.5) = -1.2（被裁剪到 0.8）
  • min = -1.2 → 限制降低幅度，防止过度降低

扩散模型适配 PPO 的困难

  • 连续动作空间：PPO originally designed for discrete actions（如 LLM 的 token 选择），扩散模型的动作是连续的（latent 空间的去噪方向），概率比 ratio 的计算更复杂
  • 多步去噪：扩散生成需要多步去噪（如 50 步），每一步都是一个动作，PPO 需要处理长序列的信用分配（credit assignment）
  • Critic 成本高：Critic 通常和 Actor 同规模，扩散模型本身很大，再加一个 Critic 显存翻倍
  • 训练不稳定：Actor-Critic 训练容易震荡，Critic 估计不准会导致优势函数偏差，进而影响 Actor 更新
  • 在线采样成本高：每轮训练都需要用当前策略生成新视频，扩散生成计算成本高

优点：① 可以利用连续 reward 信号——RM 输出的连续分数可以充分利用；② 理论保证成熟，在 LLM 上广泛验证；③ 适合连续动作空间（扩散模型的 latent 是连续的）

缺点：① 训练不稳定——Actor-Critic 训练容易震荡；② 需要 Critic 网络——增加显存和计算成本（Critic 通常和 Actor 同规模）；③ 扩散连续动作空间困难——PPO originally designed for discrete actions，适配扩散需要额外工作；④ 在线采样成本高

③ GRPO（Group Relative Policy Optimization，组内相对策略优化）

提出：DeepSeek，2024（用于 DeepSeekMath / DeepSeek-R1）

核心思想：PPO 的简化版，去掉 Critic，用组内采样的 reward 均值作为基线，计算相对优势。省掉 Critic 网络，降低显存。

流程：

  1. 训练 reward model（RM）
  2. 同一个 prompt 下采样一组（group）视频（通常 8-16 个），保证组内多样性
  3. RM 评估每个视频得到 reward r_i
  4. 计算组内相对优势：A_i = (r_i - mean(r)) / std(r)——这个视频比组内平均好多少
  5. 用 PPO 风格的裁剪目标更新策略，但不需要 Critic（用组内均值代替 V(s)）

损失函数：

L_GRPO = E[ min( ratio·A_i, clip(ratio, 1-ε, 1+ε)·A_i ) ]，其中 A_i = (r_i - mean(r)) / std(r)

优点：① 省显存——不需要 Critic 网络，显存占用显著降低；② 适合大 batch 训练；③ 组内相对优势比绝对优势更稳定（消除 RM 整体偏差）；④ 在 LLM（DeepSeek-R1）上效果出色

缺点：① 需要组内多样样本——同一个 prompt 采样 8-16 个视频，采样成本高；② 对采样策略敏感——组内样本多样性不足会导致优势估计偏差；③ Flow-GRPO 需要适配流匹配——GRPO originally for LLM，适配扩散/流匹配需要额外工作；④ 扩散模型上效果非最优（论文对比实验证明）

④ 直接 Reward 最大化（Seedance 1.0 选择）——最优

核心思想：不经过偏好对或优势函数，直接最大化 reward model 的输出。训练时模拟推理流程，生成视频后用 RM 评估，直接用 reward 作为损失信号。

流程：

  1. 训练三个维度的 reward model（Foundational/Motion/Aesthetic）
  2. 训练时模拟推理流水线，直接预测 x0（干净视频）
  3. 三个 RM 同时评估生成的 x0，得到三个奖励分数
  4. 计算复合奖励：R = w₁·R_found + w₂·R_motion + w₃·R_aesth（线性组合）
  5. 直接最大化复合奖励：Loss = -R（可带 KL 正则防止策略漂移）
  6. 多轮迭代：模型生成新视频 → RM 评估 → 模型更新 → 再生成，逐步提升上限

损失函数：

L = - ( w₁·R_foundational + w₂·R_motion + w₃·R_aesthetic ) + β·KL(π||π_ref)

优点：① 充分利用三维度连续 reward 信号——不是二分类偏好，而是连续分数，信息更丰富；② 简单直接——不需要 Critic、不需要偏好对、不需要组内采样；③ 扩散模型上效果最优（论文对比 DPO/PPO/GRPO 证明）；④ 计算效率高——省去 Critic 和组内采样的额外成本；⑤ 多轮迭代逐步提升性能上限

缺点/风险：① 需要高质量 reward model——RM 的偏差直接影响生成质量（reward hacking 风险）；② 可能过拟合到 RM 的偏差；③ 需要仔细平衡三个维度的权重（论文未披露具体权重）

5.5 超分 RLHF 框架（Super-Resolution RLHF）

在 Diffusion Refiner 上也应用 RLHF（可视为基于扩散的条件生成模型）：

  • 低分辨率 VAE latent 空间表示作为超分模型的条件输入
  • 生成的高分辨率视频由多个 Reward Model 评估
  • 直接最大化这些 reward 信号的线性组合
  • 关键：RLHF 直接应用于加速后的 Refiner 模型，在低 NFE 场景下有效增强运动质量和视觉保真度，同时保持计算效率

L1

设计目的：Base 模型 RLHF 后到 Refiner 超分会引入新的伪影（超分过程可能放大 Base 的缺陷、或引入锐化/纹理伪影），在加速后的 Refiner 上直接做 RLHF 可以针对超分过程的特有缺陷进行优化，确保最终输出（而非中间 480p 输出）的质量对齐人类偏好，同时在低 NFE（少步去噪）场景下有效增强运动质量和视觉保真度。

Base Model RLHF vs Refiner Model RLHF 关系详解

核心结论：是两次独立的 RLHF，级联进行，不是只做一次。

完整流程（级联两阶段）：

阶段1：Base Model RLHF（480p 内容对齐）

Base Model 预训练 → CT → SFT → Base Model RLHF（直接最大化三维度复合奖励，多轮迭代）

↓ 输出：RLHF 后的 Base Model，生成 480p 视频，内容层面（图文对齐/运动/美学）对齐人类偏好

阶段2：Refiner Model RLHF（720p/1080p 超分对齐）

Refiner 预训练（从 Base 初始化）→ 蒸馏加速 → Refiner RLHF（条件输入 = RLHF 后 Base 生成的 480p latent，最大化奖励线性组合）

↓ 输出：RLHF 后的加速 Refiner Model，将 480p 超分到 720p/1080p，超分过程对齐人类偏好

两次 RLHF 对比：

对比维度Base Model RLHF（4.4.3）Refiner Model RLHF（4.4.4）
作用对象 Base Model（480p 生成） Diffusion Refiner（720p/1080p 超分）
解决什么问题 内容层面对齐：图文对齐、运动质量、美学质量 超分过程对齐：超分伪影、锐化过度、纹理失真
条件输入 无（T2V 无条件生成 / I2V 第一帧条件） 低分辨率 VAE latent（来自 Base Model 输出）
奖励最大化方式 直接最大化复合奖励（composite rewards） 直接最大化奖励的线性组合（linear combination）
特殊点 多轮迭代学习（扩散模型 ↔ RM） 直接在加速后的 Refiner（蒸馏后、低 NFE）上做 RLHF
顺序 先做 后做（基于 RLHF 后的 Base 输出）

为什么要分两次做？

  • 只做 Base RLHF 不够：Base 对齐了 480p 内容质量，但 Refiner 超分过程可能引入新伪影（放大 Base 缺陷、锐化过度、纹理失真），最终 1080p 输出质量不一定对齐偏好
  • 只做 Refiner RLHF 不够：如果 Base 的内容质量没对齐（图文不对齐、运动不自然），Refiner 再怎么超分也救不回来——超分只能提升分辨率，不能改变内容
  • 两次级联最优：Base RLHF 确保"内容对"，Refiner RLHF 确保"超分好"，两者配合才能让最终 1080p 输出在内容和画质上都对齐人类偏好

⑥ 推理加速与蒸馏

6.1 DiT 模型加速：三阶段蒸馏管线

阶段一：TSCD 一致性蒸馏（4x 加速）

采用 Trajectory Segmented Consistency Distillation (TSCD) 技术，最初由 HyperSD 提出：

  • 将去噪轨迹划分为多个片段（segments）
  • 在这些片段之间强制预测状态和目标状态的一致性
  • 使学生模型能用更少步数学习扩散过程的精确近似
  • 效果：DiT 模型实现 4x 加速，在速度和保真度之间取得强平衡

L1

阶段二：Score Distillation（进一步加速）

引入来自 RayFlow 的 Score Distillation：

  • 使用期望噪声一致性（expected noise consistency）将学生模型预测的噪声（即 score function）与教师对齐
  • 支持每个样本的轨迹级优化（trajectory-level optimization）
  • 即使在低 NFE 下也能实现更稳定、更自适应的采样
  • 效果：有效改善泛化，减少快速生成时的伪影

L1

阶段三：多步对抗蒸馏（质量提升）

将来自 APT 的对抗训练策略扩展到多步蒸馏设置：

  • 纳入人类偏好数据进行监督
  • 一个学习到的判别器（discriminator）引导学生模型朝向人类判断偏好的输出
  • 效果：有效缓解激进加速带来的伪影，增强感知真实感

最终蒸馏效果：蒸馏模型在四个专家评估维度（prompt 对齐、运动质量、视觉保真度、源图一致性）上与原始模型取得可比结果。

设计目的：为什么用三阶段组合而非单一蒸馏方法：① TSCD（HyperSD）解决"大幅加速但保真度下降"问题，通过轨迹分段一致性实现 4x 加速；② Score Distillation（RayFlow）解决"低 NFE 下采样不稳定"问题，通过期望噪声一致性实现轨迹级优化，减少快速生成伪影；③ 多步对抗蒸馏（APT扩展）解决"激进加速带来感知真实感下降"问题，通过人类偏好数据+学习判别器引导输出朝向人类偏好。三阶段递进：先求速度→再求稳定→最后求感知质量，单一方法无法同时兼顾三者。

6.2 VAE 优化：Thin Decoder（2x 加速）

问题发现：在视频生成任务中，从 latent 空间解码到像素空间的计算成本显著。Profile VAE 解码器发现靠近像素空间的阶段主导延迟。

解决方案：

  1. 在这些阶段收窄通道宽度（narrowing the channel widths）
  2. 设计一个瘦 VAE 解码器（thin VAE decoder）
  3. 使用固定的预训练编码器重新训练瘦解码器

效果：实现 2x 加速，端到端视频生成的视觉质量无损失。

  • 评测标准制定：与电影导演专家合作共同开发评测维度和标准
  • 评测方式：详细的人工专家评测，使用 GSB（Good-Same-Bad） 指标进行对比分析
  • 评测维度：与电影导演合作制定四大维度，每维度含细分子项：
    • Motion Quality（运动质量）：结构准确性（structural accuracy）、运动合理性（motion plausibility）、运动稳定性（motion stability）、运动生动性（motion vividness）
    • Prompt Following（指令遵循）：动作响应（action responsiveness）、主体描述保真度（subject description fidelity）、风格一致性（stylistic conformity）、辅助实体融入（incorporation of auxiliary entities）、运动时序对齐（temporal alignment of motion）、相机行为（camera behavior）、环境描绘准确性（environmental depiction accuracy）
    • Aesthetic Quality（美学质量）：视觉纹理（visual texture）、AI 感可感知度（perceptibility of AI sense）、材质细节保真度（material detail fidelity）、美学意图的艺术表达（artistic expression of aesthetic intent）
    • Preservation（源图一致性，仅 I2V）：主体一致性（subject consistency）、风格一致性（stylistic coherence）、材质保真度（material fidelity）、视觉内容对齐（visual content alignment）、色彩光照一致性（consistency in color and lighting）
  • Prompt 分类体系：Subject（主体）、Subject Description（主体描述）、Action（动作）、Action Description（动作描述）、Camera（相机）、Aesthetic description（美学描述），T2V 和 I2V 各 300 条 prompt 在上述类别中均匀分布
  • 应用场景覆盖：特效（special effects）、电商（e-commerce）、专业生成内容 PGC（professional-generated content）

创新点核查总结论

Seedance 1.0 的核心差异化在于"解耦时空层+MMDiT+MM-RoPE的架构组合"和"三维度RM+直接reward最大化的RLHF方案"，这两点有明确的技术细节和一定的实验支撑（Reward曲线、算法对比结论）。其余创新点（数据管线、统一任务、级联超分、蒸馏加速）多为通用方法的组合创新，有定性对比或性能数据但缺少数值消融。

消融实验整体情况：7个核心创新点中，仅1个（三维度RM+直接reward最大化）有明确的算法对比实验和Reward曲线，1个（级联超分）有定性对比图，1个（蒸馏加速）有质量验证结论，其余4个完全无数值消融。论文的消融实验覆盖不足，无法精确判断各组件的增量贡献。

对 V0.1 方案的启示：① 解耦时空层+MMDiT是经过验证的高效架构组合；② 直接reward最大化在视频生成RLHF中优于DPO/PPO/GRPO；③ 三阶段蒸馏管线是工程落地的可行方案；④ 多镜头原生支持需要MM-RoPE类位置编码设计。

⑪ 对 V0.1 从零训练方案的修订建议

对我们最有价值的五条可复用技术：

  1. 数据管线五步法（镜头分割→覆盖修正→质量安全过滤→语义去重→分布重平衡）+ 密集 caption 系统（Tarsier2，动态+静态特征分类），可直接回填 V0.1 方案 C 节
  2. 解耦时空层 + MMDiT + MM-RoPE 架构，空间层多模态自注意力（双权重）+ 时间层仅视觉注意力（窗口划分），文本 token 仅参与空间层——这是实现 T2V/I2V 联合和原生多镜头的关键，可回填 V0.1 方案 D 节
  3. 四阶段渐进式训练课程（256px T2I → 256px 联合 12fps → 640px → 24fps）+ CT 阶段 I2V 20%→40% + 双 caption 设计（长 caption + 短 caption 仅运动），可回填 V0.1 方案 E 节
  4. 三维度 Reward Model（Foundational VLM架构 + Motion 专用 + Aesthetic 关键帧输入）+ 直接 reward 最大化（对比 DPO/PPO/GRPO 最优）+ 多轮迭代学习，可回填 V0.1 方案 F 节
  5. 三阶段蒸馏管线（TSCD 4x → Score Distillation → 多步对抗蒸馏+人类偏好）+ VAE thin decoder 2x 加速，可回填 V0.1 方案 G 节

SFT 模型合并技巧（在不同子集上训练独立模型再合并）和超分 RLHF（在加速后的 Refiner 上直接做 RLHF）也是值得跟进的工程技巧。
